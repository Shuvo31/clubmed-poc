## ADDED Requirements

### Requirement: Widget SHALL load zero external scripts or stylesheets
The village map widget HTML SHALL NOT contain any `<script src="...">` or `<link href="...">` tags that reference external CDN URLs. All JavaScript and CSS MUST be inlined within `<script>` and `<style>` tags in the HTML document.

#### Scenario: No external resource tags in generated HTML
- **WHEN** the widget HTML is generated by `_generate_village_map_html`
- **THEN** the HTML string SHALL contain zero `<script src=` attributes and zero `<link href=` attributes pointing to external origins

#### Scenario: Widget renders without network access to CDN origins
- **WHEN** the widget is loaded in an iframe where `unpkg.com`, `cdn.tailwindcss.com`, and `api.mapbox.com` JS/CSS requests are blocked by CORS
- **THEN** the widget SHALL still render the map, markers, and village list UI completely

### Requirement: Widget SHALL use Leaflet with OpenStreetMap tiles
The widget SHALL use the Leaflet library for map rendering with OpenStreetMap tile layers. The Leaflet JS and CSS MUST be inlined in the HTML. The only permitted external network requests at render time are tile image fetches from OpenStreetMap tile servers.

#### Scenario: Map renders with OpenStreetMap tiles
- **WHEN** the widget HTML is loaded in a browser
- **THEN** an interactive map SHALL be displayed using tiles from `tile.openstreetmap.org`

#### Scenario: Leaflet library is inlined
- **WHEN** inspecting the widget HTML source
- **THEN** the Leaflet JS library code SHALL be present inside a `<script>` tag (not loaded from a `src` URL)
- **AND** the Leaflet CSS SHALL be present inside a `<style>` tag (not loaded from an `href` URL)

### Requirement: Widget SHALL NOT depend on React or Tailwind
The widget SHALL be implemented in vanilla JavaScript without React, ReactDOM, or any UI framework. Styling SHALL use plain CSS in an inline `<style>` block without Tailwind or any CSS framework.

#### Scenario: No framework references in HTML
- **WHEN** inspecting the widget HTML source
- **THEN** there SHALL be no references to `React`, `ReactDOM`, `createElement`, or `tailwindcss`

### Requirement: Widget SHALL NOT require a Mapbox access token
The widget SHALL function without any Mapbox access token. The `mapbox_access_token` configuration field and `_FALLBACK_MAPBOX_TOKEN` constant SHALL no longer be used by the widget.

#### Scenario: Widget works with empty Mapbox token
- **WHEN** `config.json` has an empty `mapbox_access_token` field
- **THEN** the village map widget SHALL render fully with map tiles, markers, and UI

### Requirement: Widget SHALL display village markers on the map
The widget SHALL render a visual marker on the map for each village that has valid latitude and longitude coordinates. Markers SHALL be clickable.

#### Scenario: All villages with coordinates get markers
- **WHEN** the widget is loaded with N villages that have valid coordinates
- **THEN** exactly N markers SHALL appear on the map

#### Scenario: Clicking a marker selects the village
- **WHEN** a user clicks on a village marker
- **THEN** the map SHALL fly to center on that village
- **AND** the marker SHALL be visually highlighted
- **AND** the corresponding village card/item in the list SHALL be visually highlighted

### Requirement: Widget SHALL support inline and fullscreen display modes
The widget SHALL detect `window.openai.displayMode` and render two distinct layouts:
- **Inline mode**: Map fills the widget area with a horizontal scrollable carousel of village cards at the bottom.
- **Fullscreen mode**: A left sidebar lists all villages; the map occupies the remaining space to the right.

#### Scenario: Inline mode layout
- **WHEN** `window.openai.displayMode` is `"inline"` or undefined
- **THEN** the widget SHALL show a full-area map with a bottom carousel of village cards

#### Scenario: Fullscreen mode layout
- **WHEN** `window.openai.displayMode` is `"fullscreen"`
- **THEN** the widget SHALL show a left sidebar (village list) and the map to the right

#### Scenario: Dynamic mode switching
- **WHEN** `window.openai.displayMode` changes while the widget is displayed
- **THEN** the layout SHALL update to match the new mode
- **AND** the map SHALL resize to fit the new layout

### Requirement: Widget SHALL fit map bounds to show all villages on load
The widget SHALL automatically adjust the map viewport on initial load to show all village markers within the visible area.

#### Scenario: Initial map bounds
- **WHEN** the widget loads with villages spread across multiple continents
- **THEN** the map SHALL zoom and pan to fit all village markers with appropriate padding

#### Scenario: Single village
- **WHEN** the widget loads with exactly one village
- **THEN** the map SHALL center on that village at a reasonable zoom level
